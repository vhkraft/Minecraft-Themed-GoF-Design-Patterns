Legendary Ender Dragon Singleton : Bill Pugh Idiom

--------------------------------------------------------------------------------
2. MINECRAFT METAPHOR CREATIVE EXPLANATION
--------------------------------------------------------------------------------
In a single-player Minecraft world, there can only ever be one active Ender Dragon 
ruling over the End dimension. If multiple dragons could be spawned simultaneously through 
uncoordinated creation logic, the dimension's boss fight would break and corrupt world states. 
Using the Bill Pugh Singleton pattern (Initialization-on-Demand Holder idiom), the JVM 
guarantees thread-safe, lazy-loaded initialization of the single boss entity without any 
synchronization locks.

--------------------------------------------------------------------------------
3. DESIGN PATTERN TITLE & SUMMARY
--------------------------------------------------------------------------------
Singleton Pattern (Bill Pugh Idiom) : Ensures a class has only one instance, provides 
global access, and achieves thread-safe lazy loading via class-loader guarantees.

--------------------------------------------------------------------------------
4. DESIGN PATTERN CORE IDEA
--------------------------------------------------------------------------------
- Private Constructor: Restricts external instantiation (`new`).
- Static Inner Holder Class: Holds the single instance, loaded only when `getInstance()` 
  is called for true lazy loading.
- JVM Class-Loading Guarantees: Native thread safety without explicit `synchronized` locks.
- Serialization Defense: Overrides `readResolve()` to preserve instance uniqueness during file saves.

--------------------------------------------------------------------------------
5. NORMAL APPROACH VS. DESIGN PATTERN APPROACH
--------------------------------------------------------------------------------
- Normal Approach: Public constructors allow multiple dragon instances, leading to overlapping 
  boss fights and desynchronized world entities.
- Design Pattern Approach: Encapsulating instantiation inside a static inner holder class 
  guarantees a single, thread-safe dragon instance with optimal performance.

--------------------------------------------------------------------------------
6. FILE LIST & ORDER

7. SIMPLE INTERACTION FLOW
--------------------------------------------------------------------------------
Client -> EnderDragon.getInstance() -> Loads SingletonHolder -> Returns Single Shared Dragon Instance

--------------------------------------------------------------------------------
8. INTERVIEW TIP
--------------------------------------------------------------------------------
Explain that the Bill Pugh idiom is the industry-standard way to implement Singletons in Java 
when you want thread safety and lazy loading without the boilerplate overhead of Double-Checked Locking. 
It relies entirely on the JVM's class-loading mechanics to guarantee that the inner helper class 
is initialized only once, safely, and concurrently.
